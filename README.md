# AvenirOS — лендинг

Маркетинговая страница продукта **AvenirOS** (ERP + CRM + финансы + проекты).
Язык страницы — узбекский (латиница). Русская и английская версии не сделаны:
переключатель в шапке честно помечает их как «tez orada», а не ведёт в никуда.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3003
npm run build && npm start
```

Порт 3003 занят намеренно: 3000 держит сам ERP, 3001 — avenir.uz, 3002 —
лендинг магазина. Так три стенда живут одновременно.

## Что здесь важно понимать

**Макеты интерфейса — не скриншоты.** Дашборд, канбан CRM, финансы, проекты,
загрузка команды и AI-ассистент собраны вёрсткой (`components/product/*`) по
настоящим экранам AvenirOS. Поэтому текст остаётся текстом, числа считаются на
глазах, страница не тянет мегабайты картинок, а на телефоне блоки
перестраиваются, а не мылятся.

**Цвета взяты из продукта, а не подобраны.** Токены в `app/globals.css`
скопированы из `apps/web/app/globals.css` репозитория Avnir_OS: тёмная сторона
(`#0d1117`, `#131b26`, `#2563eb`, `#34d399`…) — это тёмная тема самого
интерфейса. Сайт и продукт обязаны выглядеть как одна вещь.

**Цифры — демо, и это подписано.** Выручка 3.480.000.000, воронка 596.000.000,
51 лид, конверсия 66,67%, здоровье компании 45/100 — всё со стенда
демо-организации. Везде, где они показаны, стоит пометка «Demo ma'lumot», а
компании в CRM (Korzinka, Payme, Humans…) — примеры карточек, а не клиенты.

**Ничего не обещано сверх правды.** Нет придуманных отзывов, логотипов
клиентов, метрик эффекта, сроков внедрения и цен. AI-ассистент показан как
раздел, который есть, а прогнозы и детект рисков подписаны «ishlab
chiqilmoqda» — ровно так, как компания сама пишет о нём на avenir.uz.

**Форма демо ничего не имитирует.** Приёмника у неё пока нет, поэтому после
отправки она не рисует «спасибо, заявка принята», а честно говорит, что
отправка не подключена, и даёт живые каналы (Telegram, телефон). Когда ручка
появится — менять надо ровно одну функцию `submit` в
`components/sections/cta.tsx`.

## Проверки

```bash
npm run dev                       # стенд должен быть поднят
node scripts/qa.mjs               # 6 ширин: снимки + переполнения + ошибки страницы
node scripts/qa.mjs --full        # снимки страницы целиком
node scripts/interactions.mjs     # то, что нажимается: модули, FAQ, форма, меню, якоря
npx tsc --noEmit && npx eslint .
```

`scripts/qa.mjs` падает, если хоть на одной ширине что-то вылезло за экран или
в консоли появилась ошибка. Горизонтальную прокрутку ВНУТРИ рамки макета
(канбан на телефоне) он не считает поломкой — это задумано.

Снимки складываются в `.qa/` (в git не попадает).

## Структура

```
app/                     layout (шрифт, SEO, разметка), globals.css (токены), page.tsx (порядок секций)
components/site/         шапка и подвал
components/sections/     16 секций страницы
components/product/      макеты интерфейса AvenirOS
components/ui/           появление при прокрутке, счётчик, каркас секции
lib/demo.ts              демо-данные (числа со стенда)
lib/format.ts            формат чисел — точками, как в продукте
scripts/                 браузерные проверки
```

## Мотивация решений

- **Без анимационной библиотеки.** Появление блоков — IntersectionObserver плюс
  CSS-переход, первый экран — CSS-анимация с задержками. Это десятки блоков;
  тащить ради них JS-анимацию в каждый узел — вес там, где хватает трёх строк.
- **Наблюдатель растянут вверх** (`rootMargin: 100000px …`). Без этого блок,
  проскочивший экран между кадрами (переход по якорю, быстрый флик), не получал
  ни одного уведомления и оставался невидимым навсегда — половина страницы
  выглядела пустой.
- **Счётчик резервирует ширину** итогового числа: иначе строка «дышит» на
  каждом кадре и тянет за собой соседей. CLS страницы — 0.
